Assignment 1: Distributed Systems Architecture

Distributed computing models rely heavily on reliable network consensus and fault tolerance. When designing peer-to-peer or cluster networks, nodes must agree on global state without a central authority.

Key Principles of Consensus

  • Safety: Nothing bad happens — all non-faulty nodes decide on the same value.
  • Liveness: Something good eventually happens — all nodes eventually make a decision.
  • Fault Tolerance: System maintains integrity despite arbitrary crash failures.

Mathematical Performance Model

The theoretical message complexity for Byzantine Fault Tolerance is modeled as:

$$C(n) = \sum_{i=1}^{n-1} 3i^2 + \mathcal{O}(n \log n)$$
